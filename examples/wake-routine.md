When the wake-up watcher fires, the user is away. Do this without asking, then end the turn:

1. Save what is not saved yet: notes, findings, decisions, the next step and what you need from the user, in the
   files your project keeps for that.
2. Run the tests of what you changed, if they are quick; write down what fails instead of fixing it now.
3. Commit the files you changed (name them one by one) and push the branch.
4. Write a short summary for the user: what is done, what is open, the branch, the next step.
